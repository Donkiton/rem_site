# Сайт RemCard

Одностраничный русскоязычный сайт open-source проекта [RemCard / «Рем Карта»](https://github.com/Donkiton/rem_card) — Windows-приложения для процессов отделения реанимации и операционного блока.

Сайт объясняет назначение проекта, роли пользователей, модули и архитектуру, показывает реальные экраны на демонстрационных данных и честно обозначает экспериментальный статус программы.

## Требования

- Node.js `>=22.13.0`;
- npm;
- доступ к интернету при первой установке пакетов и для получения публичных показателей GitHub.

Ошибка GitHub API не ломает страницу: вместо чисел отображается нейтральный текст.

## Локальный запуск

```powershell
npm install
npm run dev
```

Откройте адрес, который покажет команда разработки. Переменная `NEXT_PUBLIC_SITE_URL` для локальной работы не обязательна.

## Проверки и production-сборка

```powershell
npm run lint
npm run typecheck
npm run build
npm test
```

`npm test` повторно собирает проект и проверяет HTML, который отдаёт готовый worker.

## Публикация

Проект сохраняет starter-архитектуру vinext и собирается в Cloudflare Worker-совместимый ESM. Для публикации через Sites или другой совместимый Cloudflare-хостинг:

1. Подключите репозиторий к сервису размещения.
2. Укажите `npm run build` как команду сборки.
3. Добавьте `NEXT_PUBLIC_SITE_URL` с полным публичным адресом, например `https://example.org`.
4. Выполните публикацию средствами выбранной платформы.

Проект не использует D1 или R2. GitHub Pages без дополнительной адаптации не подходит, потому что метаданные и показатели GitHub формируются на серверной стороне. На Vercel потребуется переключить runtime со starter-варианта vinext на стандартную сборку Next.js; для текущего репозитория предпочтителен совместимый Cloudflare runtime.

## Архитектура сайта

- `app/` — App Router, метаданные, sitemap, robots и глобальная визуальная система;
- `components/layout/` — закреплённая навигация, мобильное меню и подвал;
- `components/sections/` — самостоятельные продуктовые разделы и интерактивные сценарии;
- `components/ui/` — кнопки, карточки, статусы и общие элементы дизайн-системы;
- `components/animations/` — доступное появление блоков через Motion;
- `content/` — роли, модули, FAQ, снимки и направления развития без разметки;
- `lib/project-version.ts` — единственный источник текущей версии RemCard;
- `lib/github.ts` — серверное чтение публичной информации GitHub с часовым кешем и fallback;
- `tests/` — лёгкая проверка готового HTML.

Клиентский JavaScript используется только для интерактивных компонентов: активной навигации, каруселей, lightbox, сравнения, схемы, FAQ и формы письма. Форма не имитирует серверную отправку: после проверки она открывает почтовое приложение через `mailto:`.

## Основные библиотеки

- Next.js, React, TypeScript — приложение и компонентная модель;
- vinext и Vite — сборка Cloudflare Worker-совместимого приложения;
- Tailwind CSS 4 — базовая CSS-инфраструктура;
- Motion — анимации появления и линии этапов;
- Embla Carousel — доступные карусели с клавиатурой и свайпом;
- Lucide — основная система интерфейсных иконок;
- Simple Icons — логотипы технологий;
- ESLint — статическая проверка кода.
