# Учебная демоверсия RemCard для сайта

Самостоятельное клиентское React-приложение, сохраняющее нативную компоновку RemCard. Использует только вымышленные локальные данные; подключения к рабочей медицинской базе нет.

Из корня сайта:

```powershell
npm.cmd run build:demo
npm.cmd run dev
```

Страницы: `/demo/`, `/en/demo/`, `/zh-CN/demo/`, `/ja/demo/`, `/de/demo/`. Встроенная карта получает язык параметром `demo-app/index.html?lang=ru`. Поддерживаются `ru`, `en`, `zh-CN`, `ja`, `de`; неизвестное значение безопасно возвращает русский.

При изменении файлов в `demo/src/` повторите `npm run build:demo` и обновите браузер. Полная команда `npm run build` всегда собирает демо перед экспортом сайта. Vite создаёт только статические ресурсы с относительными путями; папка результата `public/demo-app/` не хранится в Git.

## Сценарий

Введите препарат над таблицей назначений, выберите характеристики и время, затем откройте «Роли» → «Медсестра». ЛКМ по X означает выполнение, ПКМ — невыполнение, повторный клик отменяет отметку. Общий баланс учитывает каждый выполненный приём. Показатели вводятся слева; выведение — во вкладке баланса. Время учебного сценария фиксировано на12:00. «Сбросить демо» возвращает исходные данные.

Перевод выполняется при отображении: идентификаторы пациентов, категории, дозы и расчёты не зависят от языка. Состояние хранится в localStorage под ключом `remcard-faithful-demo-v2`, общее для всех языков одного origin. Сетевой многопользовательской синхронизации нет.

## Проверка

```powershell
npm.cmd run test:demo
npm.cmd run build
npm.cmd run test:static
```

Каталоги `src/locales/*.json` покрывают интерфейс, подписи, ошибки, динамические события и учебные данные. Основные экраны и исходные иконки взяты из проекта RemCard. Фиолетовые значки сохранения в строках назначений не отображаются. Отключённые функции и ограниченная точность демонстрации явно обозначены на странице сайта и внутри самой карты.
